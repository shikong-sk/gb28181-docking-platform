# GB28181 对接平台 - 项目概述

## 1. 项目简介

**gb28181-docking-platform** 是一个基于 GB/T 28181 国家标准实现的视频监控对接平台。该项目实现了 GB/T 28181-2016《公共安全视频监控联网系统信息传输、交换、控制技术要求》中规定的设备接入、实时视频点播、历史录像回放、云台控制等核心功能。

## 2. 项目背景

### 2.1 GB/T 28181 标准

GB/T 28181 是中国国家标准，全称为《公共安全视频监控联网系统信息传输、交换、控制技术要求》。该标准规定了视频监控联网系统中信息传输、交换、控制的互联结构、通信协议、传输要求、设备功能及性能要求等。

该标准广泛应用于：
- 公安视频监控系统
- 智慧城市视频监控
- 交通监控管理系统
- 校园安全监控系统
- 各类视频监控联网平台

### 2.2 项目定位

本项目作为一个 GB28181 平台对接中间件，主要解决以下问题：

1. **设备接入**: 支持符合 GB28181 标准的视频监控设备接入
2. **协议转换**: 将 GB28181 协议转换为标准的 RESTful API 接口
3. **媒体服务集成**: 与 ZLMediaKit 流媒体服务器集成，提供视频流转发能力
4. **统一管理**: 提供设备管理、通道管理、录像管理等统一管理能力

## 3. 核心功能

### 3.1 设备管理

- 设备注册与认证
- 设备目录查询
- 设备状态监控
- 设备心跳保活

### 3.2 视频播放

- **实时视频**: 支持实时视频点播，获取设备实时视频流
- **历史回放**: 支持历史录像回放，可指定时间范围
- **流媒体转换**: 支持 RTP/RTSP/RTMP/HLS 等多种协议输出

### 3.3 云台控制

- 镜头上下左右移动
- 镜头变倍变焦
- 预置位管理
- 巡航控制

### 3.4 录像管理

- 历史录像查询
- 录像回放控制
- 录像下载

### 3.5 目录服务

- 设备目录同步
- 通道信息查询
- 设备信息更新

## 5. 技术特点

### 5.1 模块化设计

项目采用 Maven 多模块架构，各模块职责明确，易于扩展和维护：

- **annotation**: 自定义注解模块，提供 Web 层注解支持
- **common**: 公共工具模块，提供通用工具类和配置
- **orm**: 数据持久层模块，负责数据库操作
- **gb28181-sip**: SIP 协议栈模块，处理 GB28181 SIP 信令
- **zlmediakit-service**: 流媒体服务模块，封装 ZLMediaKit API
- **gb28181-service**: 核心业务模块，实现 GB28181 业务逻辑
- **api**: RESTful API 模块，对外暴露服务接口
- **starter**: 应用启动模块，Spring Boot 入口

### 5.2 技术亮点

1. **标准 SIP 协议栈**: 基于 JAIN-SIP 实现，完整支持 GB28181 信令交互
2. **异步处理**: 支持 DeferredResult 异步响应，提升系统吞吐量
3. **流媒体集成**: 与 ZLMediaKit 深度集成，支持多种视频协议
4. **OpenAPI 文档**: 集成 SpringDoc，自动生成 API 文档
5. **Docker 支持**: 支持 Docker 容器化部署
